# Формат манифеста сборки сервера

Манифест — JSON-файл на любом статическом хостинге. Лаунчер скачивает его перед каждым запуском
(если в настройках включена синхронизация) и приводит папку сборки к описанному состоянию.

```json
{
  "formatVersion": 1,
  "id": "zero-zone",
  "name": "Нулевая зона",
  "version": "1.4.2",
  "changelog": "Добавлен мод на паразитов, обновлён Create",
  "icon": "https://example.com/zero/icon.png",

  "minecraft": "1.20.1",
  "loader": { "type": "forge", "version": "47.3.0" },

  "java": { "minMemory": 2048, "maxMemory": 6144, "args": ["-XX:+UseG1GC"] },
  "server": { "address": "play.example.com", "port": 25565, "autoConnect": true },

  "managedDirs": ["mods"],
  "keep": ["mods/optifine*.jar", "mods/journeymap*.jar"],
  "locked": true,

  "files": [
    { "path": "mods/parasites-1.0.jar", "sha1": "…", "size": 123456 },
    { "path": "config/parasites-common.toml", "sha1": "…", "size": 812 },
    { "path": "options.txt", "sha1": "…", "size": 4096, "mode": "once" },
    { "path": "mods/big-mod.jar", "url": "https://cdn.example.com/big-mod.jar", "sha1": "…", "size": 99999999 }
  ]
}
```

## Поля

| Поле | Обязательно | Описание |
|---|---|---|
| `minecraft` | да | Версия Minecraft |
| `loader.type` | нет | `vanilla`, `forge`, `neoforge`, `fabric`, `quilt` |
| `loader.version` | нет | Конкретная версия, `latest` или `recommended` (только Forge) |
| `id` | нет | id сборки у игрока (имя папки). Без него берётся из `name` |
| `version` | нет | Версия сборки — показывается игроку, по ней определяется «есть обновление» |
| `java` | нет | Память и аргументы JVM по умолчанию для этой сборки |
| `server` | нет | Сервер; при `autoConnect: true` игра сразу подключается к нему |
| `managedDirs` | нет | Папки, где лаунчер удаляет всё, чего нет в манифесте. По умолчанию `["mods"]` |
| `keep` | нет | Шаблоны путей, которые не удаляются даже в `managedDirs` (`*` — внутри папки, `**` — с подпапками) |
| `locked` | нет | `true` (по умолчанию) — игрок не может сменить сервер в настройках сборки |
| `files[].path` | да | Путь внутри игровой папки, только `/`, без `..` |
| `files[].sha1`, `size` | желательно | Проверка целостности; без sha1 файл качается только если его нет |
| `files[].url` | нет | Полный адрес. Без него файл берётся по `path` относительно адреса манифеста |
| `files[].mode` | нет | `once` — положить, только если файла нет (настройки игрока не затираются) |
| `files[].side` | нет | `client` / `server` / `both`; файлы `server` клиент не качает |

## Что происходит при синхронизации

1. Параметры сборки (версия, модлоадер, память, сервер) обновляются из манифеста.
2. Каждый файл проверяется по sha1 и при необходимости перекачивается.
3. Файлы, которые были в прошлой версии манифеста, но исчезли из новой, удаляются.
4. В `managedDirs` удаляется всё постороннее (кроме `keep` и модов, которые игрок поставил через каталог лаунчера).
5. Если сервер недоступен, но сборка уже синхронизировалась раньше, игра запускается с тем, что есть.

Генерировать манифест вручную не нужно — см. `tools/build-manifest.js`.
